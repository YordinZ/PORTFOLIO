## Projects

### FacturaIQ — Billing Analytics Dashboard
`React · TypeScript · Node.js · PostgreSQL · Docker · JWT · GitHub Actions`  
Full-stack BI platform with CSV ingestion, KPI dashboards, JWT auth, and modular architecture. Deployed on Railway/Render.

### Background Remover — Computer Vision App
`React · Python · ONNX Runtime · rembg · Hugging Face · Docker · Streamlit`  
ML web app for automated background removal using U2Net (ONNX). Uses Hugging Face model weights, REST backend + local Streamlit version with in-memory inference.

### Statistical Analysis — Personality & Nutrition
`Python · Pandas · SciPy · statsmodels · Seaborn`  
Full EDA pipeline with ANOVA, MANOVA, Logistic Regression for classification, and OLS regression for caloric density prediction.

### Unsupervised Learning — Clustering
`Python · scikit-learn · K-Means · DBSCAN · Matplotlib`  
Applied K-Means and DBSCAN to real-world datasets; evaluated quality via Elbow Method and Silhouette Score.

### Hand Gesture Detection
`Python · OpenCV · MediaPipe · NumPy`  
Real-time hand landmark detection on live video with optimized NumPy processing pipeline.
